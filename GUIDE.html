La Vie à Babi — mise en ligne

Tout se fait dans le navigateur. Rien à installer sur ton ordinateur.

Dans ce guide, remplace PSEUDO par ton nom d'utilisateur GitHub.

A. Mettre le jeu en ligne (GitHub Pages)

À la fin de cette partie, le jeu marche en mode démo : les autres joueurs sont simulés.

A1. Créer ton compte

  1. Va sur github.com et clique sur Sign up.
  2. Choisis un nom d'utilisateur simple, en minuscules, par exemple fadoh-ci. Il apparaîtra dans l'adresse du jeu.

A2. Créer le dépôt du jeu

  1. En haut à droite, clique sur + puis New repository.
  2. Dans Repository name, écris exactement PSEUDO.github.io (avec ton pseudo).
  3. Laisse Public coché, puis clique sur Create repository.

A3. Déposer les fichiers

  1. Sur ton PC, fais un clic droit sur la-vie-a-babi-web.zip puis Extraire tout.
  2. Ouvre le dossier site.
  3. Sur la page GitHub du dépôt, clique sur le lien uploading an existing file.
  4. Sélectionne tous les fichiers du dossier site (Ctrl + A) et glisse-les dans la page.
  5. Attends que tous les fichiers apparaissent, puis clique sur Commit changes.
Le fichier .nojekyll peut être caché par Windows. Il ne sert qu'à l'étape C. S'il n'est pas déposé, on le créera plus tard.

A4. Allumer le site

  1. Dans le dépôt, clique sur Settings, puis à gauche sur Pages.
  2. Sous Branch, choisis main et /(root), puis clique sur Save.
  3. Attends 1 à 2 minutes, puis ouvre https://PSEUDO.github.io.

B. Activer le vrai multijoueur (Firebase)

B1. Créer le projet

  1. Va sur console.firebase.google.com avec ton compte Google.
  2. Clique sur Créer un projet et appelle-le la-vie-a-babi.
  3. Tu peux désactiver Google Analytics. Clique sur Créer le projet.

B2. Activer les comptes par e-mail

  1. Menu de gauche : Créer (Build) > Authentication > Commencer.
  2. Choisis Adresse e-mail/Mot de passe, active le premier interrupteur, puis clique sur Enregistrer.

B3. Créer la base de données

  1. Menu de gauche : Créer > Firestore Database > Créer une base de données.
  2. Emplacement : choisis une région en Europe (par exemple europe-west1). C'est la plus proche d'Abidjan.
  3. Choisis Démarrer en mode production, puis Créer.

B4. Coller les règles de sécurité

  1. Dans Firestore, ouvre l'onglet Règles.
  2. Efface tout le texte.
  3. Ouvre le fichier firestore.rules (du dossier site) avec le Bloc-notes, copie tout et colle-le.
  4. Clique sur Publier.
Sans ces règles, n'importe qui pourrait modifier les données des autres joueurs.

B5. Relier le jeu à Firebase

  1. Clique sur la roue ⚙ à côté de Vue d'ensemble du projet, puis Paramètres du projet.
  2. En bas, dans Vos applications, clique sur l'icône </> (Web).
  3. Donne le nom La Vie à Babi. Ne coche pas « Firebase Hosting ». Clique sur Enregistrer l'application.
  4. Firebase affiche un bloc const firebaseConfig = { apiKey: "...", ... }. Garde cette page ouverte.
  5. Sur GitHub, ouvre le fichier config.js de ton dépôt et clique sur le crayon ✏ pour le modifier.
  6. Remplace chaque valeur entre guillemets par celle de Firebase : apiKey, authDomain, projectId, storageBucket, messagingSenderId, appId.
  7. Clique sur Commit changes.
La clé apiKey n'est pas un mot de passe : elle est faite pour être visible dans un site web. Ce sont les règles de l'étape B4 qui protègent les données.

B6. Autoriser ton site

  1. Firebase > Authentication > onglet Paramètres > Domaines autorisés.
  2. Clique sur Ajouter un domaine et écris PSEUDO.github.io.

B7. Vérifier

Ouvre le jeu et recharge la page deux fois. Le bandeau « Mode démo » a disparu : tu joues avec de vrais joueurs. Crée deux comptes (sur ton PC et ton téléphone) pour tester le chat et les relations.

C. Publier sur le Play Store

  1. Va sur pwabuilder.com, colle https://PSEUDO.github.io et clique sur Start.
  2. Clique sur Package for stores, puis Android, et télécharge le paquet.
  3. Le paquet contient un fichier assetlinks.json. Sur GitHub : Add file > Create new file, nomme-le .well-known/assetlinks.json, colle son contenu et valide. Ainsi, l'app s'ouvre en plein écran, sans barre d'adresse.
  4. Crée un compte développeur sur play.google.com/console. Google demande des frais d'inscription uniques : vérifie le montant sur la page d'inscription.
  5. Crée l'application et importe le fichier .aab du paquet.
Pour un nouveau compte personnel, Google peut exiger un test fermé avec une douzaine de testeurs pendant deux semaines avant la publication. Prépare des amis pour tester.

Plus tard

  • Pour changer le jeu, il suffit de remplacer index.html sur GitHub. Les joueurs reçoivent la nouvelle version automatiquement.
  • Avant de vendre quoi que ce soit (boutique, VIP), il faudra faire calculer l'argent par le serveur pour empêcher la triche.

# La Vie à Babi

Jeu de simulation de vie multijoueur à Abidjan : naître à Abobo ou à Cocody, travailler,
étudier, se faire des amis, sortir ensemble et faire sa dot, avec de vrais joueurs.

- Jouer : https://konefannia-ops.github.io
- Guide de mise en ligne (Firebase, Play Store) : `GUIDE.html`
- Pour activer le multijoueur : remplir `config.js` avec la configuration Firebase,
  puis coller `firestore.rules` dans Firestore > Règles.
